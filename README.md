## Run locally

```bash
node server.js
```

Then open `http://localhost:3000` (or the next free port).

You can also open `index.html` directly, or use any static server.

---

## Deploy on Vercel

1. Push this folder to GitHub (`Devanshu-Portfolio`)
2. Import the repo on [vercel.com](https://vercel.com)
3. Framework preset: **Other**
4. Build command: leave empty
5. Deploy

After it is live, drop the URL in `data.js` (`resumeUrl` when the PDF is ready) and in `resume/main.tex` (`portfolioURL`).
